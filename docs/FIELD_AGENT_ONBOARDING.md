# First Field Agents

MarketPulse must not manufacture agent identities. For each real pilot agent:
1. Agent creates a normal MarketPulse account and confirms email.
2. Super admin verifies the person's identity/offline onboarding record.
3. Admin → Users & Access promotes the account to Field Agent and assigns active Port Harcourt market(s).
4. Agent signs out/in to refresh server-controlled role claims/profile.
5. Agent completes the production acceptance capture at an assigned market.
6. After two independent agents are active, collect overlapping products across at least two markets so confidence can reflect cross-market confirmation.

Pilot-readiness qualification for a product is currently: at least 3 verified observations from at least 2 markets and at least 2 agents within 72 hours.
