# First Field Agents

MarketPulse must not manufacture agent identities. For each real pilot agent:
1. Agent creates a normal MarketPulse account and confirms email.
2. Super admin verifies the person's identity/offline onboarding record.
3. Admin → Users & Access promotes the account to Field Agent and assigns active Port Harcourt market(s).
4. Agent signs out/in to refresh server-controlled role claims/profile.
5. Agent completes the production acceptance capture at an assigned market.
6. After two independent agents are active, collect overlapping products across at least two markets so confidence can reflect cross-market confirmation.

## Pilot staffing slots
The production database reserves three onboarding slots without creating fake users:
- `PH-AGENT-01` → Choba Market
- `PH-AGENT-02` → Creek Road Market
- `PH-AGENT-03` → Mile 3 Market

The slots appear in Admin → Launch operations. A slot remains `open` until a real person has signed up and passed onboarding. Use Users & Access to grant the server-controlled Field Agent role and market assignment; the staffing slot is an operational tracker, not an authentication shortcut.

## Real-data coverage target
Pilot-readiness qualification for a product is: at least 3 verified observations from at least 2 markets and at least 2 agents within 72 hours. Admin → Launch operations ranks every active product by the remaining coverage gap so field collection should start with the highest-priority products rather than collecting arbitrary duplicate observations.
